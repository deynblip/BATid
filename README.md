# BATid

Department-based mobile announcement and alert system for the College of Informatics and
Computing Sciences (CICS), Batangas State University.

Stack: Kotlin, Jetpack Compose, Firebase (Auth, Firestore, FCM).

## Status
- Phase 1 (foundation): theme, shared components, navigation shell, models. Done.
- Phase 2: auth. Phase 3: student screens. Phase 4: admin screens. Phase 5: Firebase backend + push.
